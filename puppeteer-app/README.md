# 🎯 Bet9ja & Sportybet Live Predictor\n\n**Status:** ✅ Production Ready | **Version:** 2.0.0\n\nA powerful AI-driven live sports prediction system for Bet9ja and Sportybet platforms with automatic market history tracking, continuous scraping, and intelligent bet recommendations.\n\n## 🚀 Quick Start (2 minutes)\n\n```bash\n# 1. Install dependencies\nnpm install\n\n# 2. Validate system is ready\nnode validate_startup.js\n\n# 3. Start the application\nnpm start\n```\n\nThat's it! The dashboard opens automatically.\n\n## ✨ Key Features\n\n### 🤖 AI Predictions\n- **High-Risk AI Picks** → Minimum odd 3.0 (increased from 2.0)\n- **Safest Picks** → Conservative, high-confidence recommendations\n- **High-Value Picks** → Medium risk, good probability matches\n- Real-time ML model with Poisson distribution analysis\n\n### 📊 Market History\n- **Auto-Refresh** every 30 seconds when auto-scraping is active\n- **Automatic Sync** after each successful prediction\n- Historical performance tracking\n- Win rate analytics by market type\n\n### 🔄 Auto-Scraping\n- **Continuous mode** - Runs indefinitely\n- **Auto-restart** - Recovers from crashes in 10 seconds\n- **Smart polling** - Detects new rounds automatically\n- **Connection recovery** - Handles ECONNECT errors with retries\n\n### 💾 Databases\n- **SQLite** - No external DB server needed\n- **Local storage** - Works offline\n- **Multiple databases** - Separate for Bet9ja and Sportybet\n- **Automatic backups** - Optional backup system\n\n## 🛠️ System Requirements\n\n- **OS:** Windows 10+, macOS 10.14+, Ubuntu 18.04+\n- **Node.js:** 14.0.0 or higher\n- **RAM:** 4GB minimum (8GB recommended)\n- **Storage:** 5GB+ for database growth\n- **Network:** Stable internet connection\n\n## ⚙️ Configuration\n\n### First Launch\n1. **Settings Tab** → Set Output Directory (where databases are stored)\n2. **Save Settings** → Creates database automatically\n\n### Enable Auto-Scraping\n1. Go to **Live Season** or **SportyBet Live** tab\n2. Select Database (auto-detected)\n3. Toggle **Auto-Scrape** switch\n4. Market history auto-refreshes every 30 seconds\n\n## 🔧 Troubleshooting\n\n### \"ECONNECT\" Error\n```bash\n# 1. Diagnose the issue\nnode diagnose_database.js\n\n# 2. If corrupted, backup and restore:\ncp databases/virtual_football_archive.db databases/backup.db\nrm databases/virtual_football_archive.db  # Fresh DB created on restart\nnpm start\n```\n\n### Market History Not Updating\n✅ **Fixed in v2.0.0!**\n- Auto-refresh now works when auto-scraping is enabled\n- Open Market History modal for 30-second auto-refresh\n- Click \"Sync Market History\" for immediate update\n\n### Scraper Keeps Stopping\n✅ **Auto-restart implemented**\n- System now auto-restarts failed scrapers\n- Runs indefinitely with automatic recovery\n- Check Telegram notifications for status\n\n### Slow Performance\n```bash\n# 1. Optimize database\nnode diagnose_database.js  # Runs VACUUM automatically\n\n# 2. Archive old predictions\n# Use Dashboard → Utilities → Archive Old Predictions\n\n# 3. Monitor database size\n# Settings → Database Info → Monitor table sizes\n```\n\n## 📚 Documentation\n\n- **[SETUP_GUIDE.md](SETUP_GUIDE.md)** - Complete setup & troubleshooting (14 sections)\n- **[diagnose_database.js](diagnose_database.js)** - Auto-diagnose connection issues\n- **[validate_startup.js](validate_startup.js)** - Pre-flight system check\n\n## 📊 Usage Examples\n\n### Manual Scraping\n```\nLive Season Tab → Click \"Scrape Now\" → Runs once immediately\n```\n\n### Auto-Scraping\n```\nLive Season Tab → Toggle \"Auto-Scrape\" ON → Runs continuously\n                 → Click \"Market History\" → Auto-updates every 30s\n```\n\n### Database Backup\n```bash\ncp -r databases/virtual_football_archive.db databases/backup_$(date +%Y%m%d_%H%M%S).db\n```\n\n### Run Diagnostics\n```bash\nnode diagnose_database.js          #
